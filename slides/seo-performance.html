转圈圈、点不动、正文突然被挤走

  • 手机点开等超过 3 秒，大部分人都直接关了；
  • 稍微点个按钮卡半天没反应，体验极差；
  • 看着看着，上面的广告图突然刷出来，把正文一下子挤到底下去（页面跳动），体验感差，告辞，不送。
  • 核心技术基准：
    Core Web Vitals 表现优秀（LCP、INP、CLS全绿），完整的结构化数据和 sitemap站点地图，让搜索引擎直接抓取到产品、评价、文章结构，移动端绝对优先的排版与交互体验。
整理补充：原文“超过 3 秒大部分人离开”是体验提醒，不作为本课统计。LCP 看主要内容加载、INP 看交互、CLS 看布局稳定性；阈值与第 75 百分位的练习放在文末工具里。 · web.dev：Web Vitals · Google：核心网页指标与搜索

5MB 原图、没用的脚本，先减负

把那些动辄 5MB 的大高清原图压缩成 WebP 格式，把没用的脚本删一删，手机上看舒服了，核心指标自然就达标了。

整理补充：压缩图片和删脚本有助于减负，是否达标仍需实测；按尺寸与场景选择 WebP、AVIF 等合适格式，并预留图片空间。

别炫技，成熟技术栈直接上手

选择适合长线SEO、性能极快且易于维护的技术栈，高变现的能力往往来源于最简单的技术，什么 vue、什么 elementui，别！求你了，市面上那么多成熟的建站技术栈直接上手就好。

  • 静态/极速博客与内容站：
    Next.js / Astro：首屏极速加载、现代SEO支持极佳，适合需要定制化交互和工具页面的站点。
    Ghost / Hugo：专注内容输出，加载速度快，自带现代会员订阅系统（Ghost支持原生Stripe集成）。
  • 快速建站与生态集成：
    WordPress：生态成熟、插件极其丰富（适合Affiliate营销、SEO插件支持成熟），但务必配置轻量主题和CDN缓存，越重越好看的主题，加载速度非常缓慢，但说句实话，建站这么多年，我接手过的个人站点，WordPress 最多，如果你觉得比较陌生也正常，因为大多数人叫它简称： WP；
整理补充：框架名称不保证速度。Ghost 提供会员能力；Hugo 是静态站生成器，会员需额外集成。WordPress 的主题、插件和缓存配置会影响实际表现。
动手练习与检查工具

以下为整理时补充的练习，可按自己的业务填写；文章正文取自黄啊码原文段落。

把这一讲用到自己的业务

  1. 定义任务选一条真实手机路径，包含阅读、操作和提交反馈。记录设备与网络条件，避免把不同环境的数据直接比较。
  2. 识别问题分别观察主要内容加载、交互响应和页面跳动。结合报告定位对应元素或任务，不先预设一定是图片或服务器问题。
  3. 安排修复根据影响处理资源大小、脚本、空间预留或缓存。缓存涉及价格与权限时要同时保证信息正确，不只追求命中率。
  4. 同条件复测保留改动前后记录，再结合真实用户数据观察。数据缺失就说明缺失，不用一次绿灯替代整站验收。

本节交付：一份包含条件、问题位置、改动与复测结果的体验记录。练习的阈值只帮助理解指标，不给页面计算搜索排名。
