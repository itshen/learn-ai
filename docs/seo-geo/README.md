## 证据与内容修订

- 96 条作为知识点索引对应到原文章节，相关知识点共用完整段落；不再为了凑编号扩写成 96 段新教程。source-texts.json 保存来源文字，authoring-layout.json 保存每段选文的字符范围，检查器验证与原文逐字一致。
- 90%、收入设问与固定平台偏好不作为统计结论。演练品牌、参数、金额和结果不冒充真实客户案例。
- 区分抓取、索引、训练、提及、引用、推荐、来源访问和业务转化。
- 当前 Google 文档已说明 FAQ 富媒体结果停止展示，并明确其搜索不使用 llms.txt 获得特殊优化；相关旧建议已修订。
- 原文的题库收入属于作者叙述；120ms、98.6%、90%、快 100 倍等按示例或修辞处理，假设的收银系统不写成真实客户实测。
- 原站登录系统保留，客户端隐藏不作为敏感信息的权限保护。
